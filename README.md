# Hyper Notify Lab

Flutter Android notification showcase for Xiaomi → Haylou Fun → Haylou Watch Hyper.

Test notification titles, messages, emoji, priority, vibration, and Android app icons. Watch display depends on Haylou Fun's forwarding support.

## Build

GitHub Actions builds a debug APK on every push to `main`. Download the `hyper-notify-apk` artifact from Actions.

The workflow generates standard Flutter Android scaffolding in CI, so this repository keeps the portable Flutter source and Android resource overrides.
